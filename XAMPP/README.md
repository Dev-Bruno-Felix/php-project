<h1>Como instalo o XAMPP no linux:</h1>

<h2>Altere as permissoes do instalador</h2>

chmod 755 xampp-linux-*-installer.run

<h2>Execute o instalador</h2>

sudo ./xampp-linux-*-installer.run

<h1>Como inicio o XAMPP no linux:</h1>

sudo /opt/lampp/lampp start

<h1>Como eu paro o XAMPP no linux:</h1>

sudo /opt/lampp/lampp stop
